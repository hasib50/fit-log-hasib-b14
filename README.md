# FitLog — Workout Library

FitLog is a workout library web application where users can explore exercises, view workout details, create a daily workout plan, and save workouts for later. The application is designed with a simple dark interface and a responsive layout for different screen sizes.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Toastify
- REST API
- Local Storage

## Key Features

- Browse and explore different workouts from the workout library
- View detailed workout information including equipment, sets, reps, duration, calories, and instructions
- Search and sort workouts by name, muscle group, duration, calories, or rating
- Add workouts to today's plan and manage planned exercises
- Save workouts for later and manage saved exercises
- Mark completed workouts as done with toast notifications
- Remove workouts from the plan or saved list
- Responsive design for desktop, tablet, and mobile devices
- Store workout plans and saved workouts using local storage
- Custom loading state and 404 page
